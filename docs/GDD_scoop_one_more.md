# 《再铲一坨》One More Scoop — GDD v0.1

> 一句话：猫砂盆是一副牌，铲是抽，你不知道下一坨是什么。收手，还是再铲一坨？
> 类型：贪心抽卡 Roguelike（push-your-luck），局内铲钱，局外铲故事。
> 定位：短局、上瘾、可截图；一周目 20 天，2–3 小时；单人，Web 优先。
> 关系：与《屎必须铲》（《账单必须支付》换皮 demo）同源，复用撸猫/铲/腰力/账单/遗产的皮和手感，但核心循环换成贪心抽卡。

---

## 0. 设计支柱

1. **爽**：「再铲一坨」按下去那一秒是全部。翻开的动画、音效、数字，比任何系统都重要。
2. **一个动词**：从头到尾只有「铲」。铲钱是它，铲故事也是它，教学不需要第二句话。
3. **变数只从盆里来**：铲子、腰力、账单、猫的行为全部确定；唯一的不确定是这一铲翻出来什么。玩家永远知道惊喜从哪儿来。
4. **局内不说话**：局内一句话都不多，故事只在你停手的时候出现，且永远一行。

## 1. 设定

你是欠债的上门铲屎工。白天去别人家铲猫砂盆挣工钱，晚上回家铲自家那只猫的盆。账单一张接一张。猫砂盆里什么都有。

## 2. 核心循环：一盆

```
开盆（猫坐在盆边看你）
→ 再铲一坨：翻开一坨，进「今日收成」
→ 收手：收成变钱，这盆结束
→ 翻到毒屎：收成清零，这盆作废
→ 全部翻完没踩毒：「全场干净」大奖
```

- 盆里有 N 坨，其中 M 坨毒屎。**N 和 M 你知道，位置不知道。**
- 每铲耗 1 腰力，腰力也随时间流逝（沿用《屎必须铲》）。腰力见底当天收工。
- 按钮文案随贪心程度变：「收手」→「见好就收」→「你确定？」→「就一坨了，铲不铲？」

### 2.1 贪心要有依据（信息手段）

纯 50/50 不好玩。随机只决定答案在哪，设计决定你有多少办法在铲之前知道。

| 手段 | 代价 | 给什么 |
|---|---|---|
| 闻 | 腰力 | 盆里还剩几坨毒（数量不给位置） |
| 筛 | 腰力 + 一次机会 | 翻开一角看到但不铲 |
| 苍蝇 | 时间（腰力在掉） | 毒屎上有苍蝇，盯久能看出来 |
| 猫的提示 | 免费 | 盆边站着哪只猫 → 盆里大概是什么 |
| 道具 | 钱 | 地图（下一盆毒屎全显）、沙漏（这盆腰力不掉）等 |

### 2.2 最小可玩版本（MVP）

一个盆、一个按钮、闻 + 筛两个手段、五种屎（普通/金/毒/结块/蘑菇）。验证「再铲一坨」按下去爽不爽。一小时原型。

## 3. 盆里有什么（变数的全部来源）

按来源分五类，每类一种玩法感觉：

| 类 | 例子 | 玩法 | 占比 |
|---|---|---|---|
| **猫拉的** | 普通屎、金屎、双黄、结块 | 钱，安全感 | ~70% |
| **猫吞的** | 戒指、耳机、钥匙、假牙、彩票、婚戒、前任照片 | 主人给赏金，金额随主人反应；每样一句主人的话 | ~15% |
| **猫藏的** | 死虫子、毛线球、别的猫的项圈 | 道具，留着用；越怪说明猫越野，进图鉴 | ~8% |
| **时间带来的** | 化石→琥珀→猫毛、蘑菇→蘑菇王 | 没人铲的盆在酿东西，回来铲是开酒 | ~5% |
| **莫名其妙的** | 地图、沙漏、手表（倒回三铲）、镜子（复制下一坨）、一封信「别再铲了」、一扇门（盆底还有盆）、猫本人、你自己的照片 | 不给钱，改这一盆或这一天的规则 | ~2% |

规则：
- 每样东西只做一件事，翻出来那一刻生效或一句话说清。不动脑。
- 稀有度四档，翻出来的动画和音效按档升级。用耳朵就知道这一铲值不值。
- 坏东西也要好玩：毒屎、诅咒、前任照片是笑点，不是惩罚。
- 条件出现：只在第 13 铲、只在盆里剩一坨时、只在连续三天没破产时。玩家之间会传的秘密。
- **图鉴**：一百样东西，第一次翻到记一条，带主人或猫的话。翻齐一类有奖励。

### 3.1 盆有主题

主人家的盆、猫咖的盆、动物园的盆、宇航员的猫的盆、古墓的盆。每个主题一套「莫名其妙」。盆的主题就是关卡，猫砂盆是一个可以去任何地方的容器。

## 4. 构筑

铲出来的不只是钱，可以留着当牌：金屎当护身符抵一次毒；化石凑套换永久道具；蘑菇留到下一盆。道具改规则：大口铲一次翻两坨、除臭砂毒屎减一、猫薄荷让猫多拉金屎。玩家在「现在换钱」和「留着变强」之间选。

## 5. 局的结构

- **一天**：3–5 个盆（桌上并排，各有一只猫，毒屎密度不同 = 选难度）→ 收工 → 付账单 → 回家铲自家的盆。
- **一周目**：20 天。账单越来越重（沿用《账单必须支付》的账单线：水费 $20 → … → 保释金 → 税）。付不出就破产 → 遗产点买永久戒指 → 新周目。
- **骨架 roguelike，肉是设计的**：
  - 盆的构成随机，毒屎数量/提示强度/奖励梯度按天手工定曲线。
  - 信息手段是设计的，位置是随机的（扫雷结构）。
  - 穿插手工盆当节点：猫神的盆、主人的盆、下水道的盆，固定内容，有唯一解，是 boss 也是记忆点。
  - **每日盆**：全球同种子，比谁贪得最准，可晒截图。

## 6. 两个盆：别人家的 vs 自家的

| | 别人家的盆（局内） | 自家的盆（局外） |
|---|---|---|
| 猫 | 客户的猫，六种性格，随机 | 你自己那只，只有一只 |
| 内容 | 随机 | 固定，一天一坨，手工排好 |
| 目的 | 钱 | 故事 |
| 风险 | 毒屎、腰力 | 没有 |
| 铲几下 | 贪多少铲多少 | 就一坨，铲完猫说一句 |
| 翻出来的 | 什么都可能 | 今天该出的那一样 |

**别人的盆铲钱，自家的盆铲故事，都是铲。** 变数在别人的猫身上，情感在自己的猫身上，互不打架；而且这个分工本身就是故事：每天撸别人的猫挣钱，是为了养家里那只。

## 7. 叙事：局内铲屎，局外铲故事

Hades 结构：局内全爽，故事只出现在你本来就要歇的那三十秒。

**硬规则**（违反任一条就砍）：不暂停、不弹超过一行、不做选择、不改局内节奏。

**两条线**：
- **别人家的（零食）**：盆里翻出来的东西一句话，拼出六户人家的一年。图鉴里躺全文，想读的读。
- **自家的（主线）**：账单背面一行字 + 自家盆每天那一坨 + 门口那只猫一句话。20 天收尾。

**主线候选**（二选一）：
- **账单是谁寄的**：账单全是「猫叔」寄的，最后一张「税」到的时候明白他是谁。与原作账单线严丝合缝。
- **上一任铲屎工**：盆的深处偶尔翻出上一任留的字条、旧铲子、记账本，最后一样是写给你的信。与「越铲越深」绑得最紧。

**结尾**：最后一张账单「税」把你扣到一块钱。回家，自家的盆空了，猫在门口。「再铲一坨」按钮变灰。结尾就在这个按钮上。

## 8. 手感优先级

1. **铲的那一下**：端起 → 币落砂弹两下滚一滚 → 停半拍 → 全部吸向钱包每枚「叮」音高递增 → 钱包数字弹。币不落地就没有重量。
2. **手的重量**：弹簧跟随，压—拖—抬循环对齐手速。
3. **猫的反应**：压扁拉伸、♥、呼噜随连击变响；便意满屁股扭两下再「啪」。
4. **声音**：真采样分层，音高随机偏移。
5. **UI 动感**：数字弹、条有惯性、结算滚数、暴击帧停 40ms。

## 9. 与《屎必须铲》的关系

| 复用 | 换掉 |
|---|---|
| 撸猫催便、腰力实时流逝、账单/破产/遗产、猫品种、手感层 | 悬停自动铲 → **按钮「再铲一坨」**；血量/便意 → 盆里的坨数；埋屎 → 毒屎；技能树 → 道具与构筑 |

两个可以是同一个游戏的两种模式，也可以是两个游戏。先做 MVP 再定。

## 10. 风险

1. 纯赌感：信息手段不够强就是老虎机。对策：闻/筛必须便宜且有用，毒屎数量永远可知。
2. 叙事拖节奏：任何一行超过一句就砍。
3. 「莫名其妙」失控：每样只做一件事，四档稀有度，条件出现的东西不超过总量 10%。
4. 和换皮 demo 撞：先定是模式还是新作。
