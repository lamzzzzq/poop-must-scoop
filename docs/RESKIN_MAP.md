# 换皮映射表：《账单必须支付》→《屎必须铲》

> 规则：**系统与数值一律照原作**（见 `BMBP_SYSTEM.md`），本表只做「叫什么、长什么样」的替换。
> 原作没有的机制不加；原作有但数值未查到的，用 `[待核]` 标出临时值并注明依据。
> 我们此前自创的「屎六阶段演变 / 屎山 / 找屎 / 清洁度决定猫来去」全部进 §9 暂存箱，不进 v0.2。

## 1. 场景设定（一句话）

你是穷铲屎官，接了一所富豪家猫咪后院的清洁活：**上门铲屎，主人按坨付工钱**。账单一张接一张寄来，**屎必须铲，账单必须付**。（0902 方案 A：钱不在屎里，钱因为屎而来；否决了「猫吞硬币」）

## 2. 核心对象

| 原作 | 换皮 | 备注 |
|---|---|---|
| 锤子 Hammer | **铲子** | 四维不变：伤害→**臂力**、暴击→**一铲到底**、范围→**铲面**、攻速→**手速** |
| 悬停自动挥锤 | 悬停自动**撸**（停在猫上）/ 铲（停在屎上），手机手指按住拖动 | 不做点击。原作开发者原话「攻速你怎么处理」 |
| 锤击范围内全部命中 | **铲面之内的猫和屎全部吃到** | 原作锤子「大范围低伤害 vs 小范围高暴击」的取舍靠这条成立 |
| 猪跑开 → miss，连击归零 | 前摇里猫跑开 → 「扑空」 | El Loco 首击必中 → 暹罗首撸必中 |
| 存钱罐种类（Normalito/Tourist…） | **猫的品种** | 品种决定跑法、便意长短、工钱档位、等级 |
| 存钱罐实例（桌上一只猪） | **一只猫**（v0.4 起） | 猫的便意 = 猪的血量；撸满它就蹲下拉。屎是掉落，一铲收走 |
| 猪会跑/zigzag/懒得动 | **猫埋屎**：猫凭空出现→蹲→拉→扒砂盖住；抢先铲=省腰力，埋住后是带苍蝇破绽的鼓包，挖开多几下、掉落升一档 | 「目标随时间变难/消失」的换皮，屎不长腿。不做纯记忆，只靠破绽（感知不是记忆）。狸花的屎另有慢慢挪（Normalito） |
| 猪等级 1–10 提高掉落 | **猫等级 1–10** | 「这只猫吞的东西更值钱」 |
| 砸碎 → 金币宝石喷出 | 铲净 → 工钱「叮」进账，金币从铲位喷出 | 爽感原样，语义是主人按坨付钱 |
| 掉落档位（65%/32%/3%） | 这坨屎的单价档位；3% 档 = **猫屎咖啡** 彩蛋 | Piñata 的「不知道哪只装得多」= 不知道这坨给多少 |
| 桌子 | **猫砂盆 + 后院** | 场地 |
| 耐力 Stamina | **腰力**（弯腰铲屎，腰越弯越酸） | **随时间实时流逝** + 移动 + 每铲扣一点，见原作 B「drains over time while moving and smashing」；直不起腰=收工 |
| 每 10 击连击 | 每 10 铲连击 | miss 归零 |
