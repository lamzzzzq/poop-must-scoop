# 换皮映射表：《账单必须支付》→《屎必须铲》

> 规则：**系统与数值一律照原作**（见 `BMBP_SYSTEM.md`），本表只做「叫什么、长什么样」的替换。
> 原作没有的机制不加；原作有但数值未查到的，用 `[待核]` 标出临时值并注明依据。
> 我们此前自创的「屎六阶段演变 / 屎山 / 找屎 / 清洁度决定猫来去」全部进 §9 暂存箱，不进 v0.2。

## 1. 场景设定（一句话）

你是穷铲屎官，接了一所富豪家猫咪后院的活。猫什么都吞，屎里全是硬币和宝石。账单一张接一张寄来，**屎必须铲，账单必须付**。

## 2. 核心对象

| 原作 | 换皮 | 备注 |
|---|---|---|
| 锤子 Hammer | **铲子** | 四维不变：伤害→**臂力**、暴击→**一铲到底**、范围→**铲面**、攻速→**手速** |
| 悬停自动挥锤 | 悬停自动铲（手机：手指按住拖动） | 不做点击。原作开发者原话「攻速你怎么处理」 |
| 存钱罐种类（Normalito/Tourist…） | **猫的品种** | 品种决定它拉的屎的血量/掉落/行为/等级 |
| 存钱罐实例（桌上一只猪） | **一坨屎** | 屎的 HP = 结块硬度，要铲几下 |
| 猪会跑/zigzag/懒得动 | **猫刨砂把屎踢来踢去** / 埋起来不动 | 移动行为的因果换成猫，屎本身不长腿 |
| 猪等级 1–10 提高掉落 | **猫等级 1–10** | 「这只猫吞的东西更值钱」 |
| 砸碎 → 金币宝石喷出 | 铲起 → 金币宝石喷出 | 爽感来源保留原样 |
| 桌子 | **猫砂盆 + 后院** | 场地 |
| 耐力 Stamina | **腰力**（弯腰铲屎，腰越弯越酸） | **随时间实时流逝** + 移动 + 每铲扣一点，见原作 B「drains over time while moving and smashing」；直不起腰=收工 |
| 每 10 击连击 | 每 10 铲连击 | miss 归零 |
