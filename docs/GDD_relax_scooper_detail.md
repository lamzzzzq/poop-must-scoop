# 《再铲一坨》解压版 · 细化 GDD v0.1（可实现级）

> 上一份（`GDD_relax_scooper.md`）是架构，这份是规格：每个输入做什么、每个数是多少、每一户是什么。demo 在 `/relax/`，标 `[调]` 的数字等手感实测后调。

---

## 1. 屏幕与流程

```
工单页（今天去哪几户）→ 进门（这户的盆列表 + 工单）→ 盆页（俯视，核心动作）→ 盆完成 ✓ → 下一盆 → 全部 ✓ → 打包丢弃 → 评价页（星 + 一句话）→ 回工单页
```

demo 只做「盆页 + 工单条 + 评价」。

## 2. 盆页：输入状态机

竖屏 480×720，盆占中间 432×360（高度场 96×80 格，每格 4.5px）。铲子跟随指针。

| 状态 | 进入 | 每帧 | 离开 |
|---|---|---|---|
| **悬停** hover | 默认 | 铲子贴砂面滑动，不改变砂 | 按下 → 铲入 |
| **铲入** dig | 在盆内按下 | 铲刃脚印内的格子高度按 `digRate·dt` 减少，砂进铲；30% 推到脚印外沿成脊 `[调]`；脚印覆盖且挖深 ≥ 埋深的结块被端上铲 | 松开 → 抬起 |
| **抬起** lift | 松开 | 铲子上移 10px，影子拉长；铲上的砂和结块跟着走 | 横向快速移动 → 筛；在盆内再按下 → 倒回；在袋子上按下 → 倒袋 |
| **筛** sift | 抬起中指针横向速度 > 600px/s `[调]` | 铲上的砂按 `siftRate·速度·dt` 漏回铲下方格子，粒子从铲缝落下；结块不漏 | 速度降下来 → 抬起 |
| **倒袋** dump | 抬起中在袋子上按下 | 结块进袋（计数 +1，「啪」）；铲上残余砂进袋（计「带走砂」克数） | 自动回悬停 |
| **倒回** put back | 抬起中在盆内按下 | 铲上的砂和结块回到脚印处（高度场 +） | 回悬停 |

触屏：手指按住 = 按下，抬起 = 松开，左右晃 = 筛。

## 3. 砂的参数（一户一种）

| 砂 | 颜色 | 颗粒 | digRate | siftRate | 结块硬度 | 粉尘粒子/铲 | 铲容量 | 丢法 |
|---|---|---|---|---|---|---|---|---|
| 膨润土 | #d9c9a2 | 细 | 1.0 | 1.0 | 硬（筛不散） | 12 | 1.0 | 装袋 |
| 豆腐砂 | #efe6cf | 条状粗 | 1.2 | 1.6（漏得快） | 松（筛 3 下后开始掉砂壳） | 3 | 0.8（轻） | 可冲 |
| 水晶砂 | #e6f0f5 | 大颗粒 | 0.8 | 2.0 | 不结团（屎躺表面） | 0 | 1.0 | 装袋 |
| 松木砂 | #c9a878 | 木屑 | 1.1 | 1.4 | 不结团，湿处变粉 | 6 | 0.9 | 装袋/堆肥 |
| 纸砂 | #efece6 | 团 | 1.3 | 0.6（糊，漏得慢） | 糊 | 0 | 0.6 | 可冲 |

demo 做膨润土 + 豆腐砂两种，验证同一动作手感确实不同。

## 4. 实体

- **结块**：`{x, y, r(10–18), depth(0–0.25 埋深), catId}`。生成时在高度场加一个鼓包（半径 r+6，高 0.12）`[调]`，这是「找」的破绽；结块本体在鼓包下，挖到 depth 才露出。湿印：新拉的周围一圈颜色深 8%，30 秒淡掉。
- **铲子**：口宽 56px、刃深 22px、缝 4 条（筛速系数）、容量 1.0（满了砂从边上溢，粒子）。
- **袋子**：盆右下角。计数、砂克数。所有盆完成后「扎口」按钮：动画收口 + 「啪」。
- **砂量**：总高度均值 `level`，铲走的进袋就少了。低于 0.45 时工单出现「补砂」；点补砂袋子，从指针处倒砂（高度场 + 流），倒到 0.6 停。
- **猫**：盆干净（结块 0，level ≥ 0.5，砂面平整度 > 阈）后 3 秒走进来：踩两脚（局部高度扰动）、嗅、蹲 1.2 秒、拉一坨（新结块 + 鼓包 + 湿印）、刨两下（周围高度场随机 ±）、走。这一幕是「干净了」的奖励，也是下一坨的来源。

## 6. 工单数据

```js
{ id, house: '陈太太家', district: 1, cats: [{name, breed, litterPref, boxPref}], boxes: [{litter, clumps: n, level, tasks: ['scoop','refill','change']}],
  tasks: [ {t:'scoop', box:0}, {t:'refill', box:0}, {t:'bag'}, {t:'dispose', how:'bag'|'flush'|'compost'} ],
  special: '一句话特别指令', hidden: {type:'notEnoughBoxes'|'wrongLitter'|'badSpot', hint:'盆外一坨'}, review: {5:'…',4:'…',3:'…'} }
```

## 7. 评分

从 5 星起扣：结块残留每坨 −1；带走砂 > 80g −1 `[调]`；丢弃方式错 −1；补砂没做 −1；盆外那坨没处理 −1（如有）。最低 1 星。星数只决定解锁和评价文案，不扣钱。

## 9. demo 范围（`/relax/`）

- 一个盆（陈婆婆家），膨润土 / 豆腐砂可切换看手感。
