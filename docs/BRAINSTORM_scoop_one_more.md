## 方向 1 的演进（对话顺序）

1. **贪心结构**：一盆 N 坨，一铲翻一坨，任何时候可收手；毒屎清空收成。21 点 / Balatro 的骨架。
2. **贪心要有依据**：闻（知数量）、筛（看一角）、猫的提示、苍蝇。随机只决定答案在哪，设计决定你有多少办法在铲之前知道。
3. **Roguelike 还是设计好的？** → 骨架 roguelike，肉是设计的：盆随机、曲线固定；信息手段设计；手工盆当 boss 节点；每日盆（同种子）可晒。
4. **猫砂盆是宝箱**：变数只从盆里来，其他全确定。五类东西：猫拉的（钱）、猫吞的（横财+主人反应）、猫藏的（道具）、时间带来的（变化）、莫名其妙的（改规则）。稀有度四档，动画音效按档升级。
5. **叙事**：可以夹，但 → 「局内铲屎，局外看故事」（Hades 结构）。硬规则：不暂停、不超一行、不做选择。
6. **讲什么故事**：五个候选（那只猫是谁的 / 账单是谁寄的 / 六只猫六个家 / 上一任铲屎工 / 你自己的家）。推荐「账单是谁寄的」或「上一任铲屎工」。
7. **猫是自己的吗**：两只都要——盆里全是别人的猫（变数），你家有一只（情感、叙事者、破产时被收走的那个）。
8. **自家也能铲**：故事不是看的，是铲出来的。自家的盆一天一坨、固定、无风险，铲完猫说一句。最后一天盆空了，「再铲一坨」按钮变灰。

结论：**别人的盆铲钱，自家的盆铲故事，都是铲。**

## 手感优先级（从换皮 demo 的讨论带过来）

1. 铲的那一下（工钱时刻：端起→币落地弹滚→停半拍→吸向钱包→数字弹）
2. 手的重量（弹簧跟随、压拖抬循环对齐手速）
3. 猫的反应（压扁拉伸、♥、呼噜随连击变响）
4. 声音（真采样分层、音高随机偏移）
5. UI 动感（数字弹、条有惯性、结算滚数、暴击帧停）
