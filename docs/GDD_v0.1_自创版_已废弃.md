# 《屎必须铲》Poop Must Scoop — 游戏设计文档

> 一句话：你是一所猫咪后院的铲屎官。猫来了会拉，你铲；铲得干净猫就更多，猫多屎多，屎多逼你换工具，工具让你铲得更爽更多。
> 类型：主动式放置 / 增量游戏（active idle）。参照：《账单必须支付》的单局骨架 × PowerWash Simulator 的脏→净爽感 × Neko Atsume 的猫来访收集。
> 平台：Web（手机优先，桌面可玩）。单人，纯本地存档。目标时长：主线 2~4 小时，之后挂机收集。

---

## 0. 设计支柱（三条，冲突时按顺序取舍）

1. **轻松**：没有 game over，没有存档丢失，没有惩罚玩家的机制。所有「压力」只作用在猫身上（猫走、猫不来），从不作用在玩家的积累上。
2. **爽**：铲这一下是全部。音效（沙沙 → 咔 → 叮）、颗粒、连击数字、屎山崩塌，其他系统都是这一下的放大器。
3. **不动脑**：全程只有一个动词「铲」，只有一种判断「哪里有屎」。没有资源权衡、没有构筑、没有找茬。凡是需要玩家「想」的地方都用「走」代替（多走两步，不是多想两步）。

## 1. 核心反转：屎是 KPI

别的游戏屎是麻烦。在这里屎越多说明后院越红火。屎不是账单，是庄稼。放着不铲不会烂掉消失，只会**变形**、**长东西**、**招来事**。这个立场决定了所有系统的语气。

## 2. 核心循环

```
猫来访 → 猫拉屎 → 屎按时间演变 → 你铲（消耗体力，得罐头+连击）
   ↑                                        ↓
新猫被清洁度吸引 ←── 一天结束结算清洁度 ←── 体力见底收工
                          ↓
                   商店：铲子/猫砂/盆/工具/自动化
```

- **单局 = 一天**。体力见底（手酸）当天收工。玩家也可以随时点「收工」。
- **一天结束**：结算清洁度 → 新猫来 / 老猫走 → 进商店 → 下一天。
- **增量的意义**：数字变大（一铲的罐头）、数量变多（猫、屎、盆）、动词进化（一铲一块 → 一铲一排 → 整片翻起 → 无人机一扫）。

## 3. 屎：生命周期与形状

### 3.1 三个形状轴（相乘产生种类）

| 轴 | 来源 | 例子 |
|---|---|---|
| 按猫 | 每种猫固定拉法 | 布偶：圆润小球 · 橘猫：巨型条 · 无毛猫：整齐方块 · 小猫：迷你豆 · 狸花：经典螺旋 |
| 按时间 | 同一坨随时间变形 | 见 3.2 |
| 按事件 | 猫偷吃了什么 | 彩虹屎（蜡笔）· 金屎（金鱼）· 闪光屎 · 巧克力屎（假的，猫不能吃巧克力，是玩笑事件） |

所有屎必须**可爱讨喜**：emoji 质感、巧克力色系、圆角、两点眼一条笑，绝不写实。不同形状是不同精灵，不是同一张图缩放。

### 3.2 时间演变（每档是新的形状，没有「烂掉消失」）

| 阶段 | 起始时间 | 样子 | 对玩家意味着 | 惩罚性 |
|---|---|---|---|---|
| 新鲜 | 0s | 冒热气，软 | 一铲即起，**收益 ×1.5**（新鲜奖励） | 无 |
| 结块 | 6s | 裹满猫砂，硬壳 | 收益 ×1.0，铲起来「咔」最爽 | 无 |
| 招苍蝇 | 15s | 头上绕两只苍蝇 | 苍蝇 = 「屎在哪」的信号，找屎机制由此长出 | 无 |
| 臭气 | 25s | 冒绿色波纹 | 猫不肯用脏盆 → 去院子里拉 → 屎扩散到难找处；清洁度开始扣 | 软：加工作量 |
| 长蘑菇 | 40s | 顶一朵小蘑菇 | 铲时蘑菇是额外掉落（图鉴收集） | 反而有甜头 |
| 化石 | 60s | 灰白色带裂纹 | 要敲 3 下，出「化石」收藏品，罐头收益 ×0.5 | 无，是彩蛋 |

平衡原则：化石和蘑菇给**收藏品**不给钱，钱永远是新鲜的最多。勤铲是最优，偷懒是另一种乐趣，不是挨打。

### 3.3 屎山（Boss）

同一位置持续不铲，屎向上叠。盆满后继续拉，或院子同一点位堆到 5 坨以上，合并成一座**屎山**：
- 有血条（= 坨数 + 2 下），每一下敲掉一块，有碎屑。
- 敲塌那一下整座山崩成罐头雨 + 屏幕微震 + 低沉「轰」。这是本作的「存钱罐碎裂时刻」。
- 山崩总收益 = 单独铲每一坨之和 ×1.5，所以后期玩家会**故意养山来崩**，这是合法玩法。
- 屎山上可能长出稀有蘑菇/化石。

## 4. 猫：来访、性格、拉法

- 猫是后院的**访客**，不是玩家的财产。每天结算按清洁度决定来去（Neko Atsume 逻辑）。
- 每只猫：外观、拉屎形状、偏好点位、频率。示例：

| 猫 | 拉屎形状 | 偏好点位 | 频率 | 备注 |
|---|---|---|---|---|
| 狸花 | 经典螺旋 | 猫砂盆 | 中 | 初始猫 |
| 大橘 | 巨型条（value ×2，占两格） | 花坛 | 慢 | 吃得多 |
| 布偶 | 圆润小球 | 只在盆里，盆脏就憋着不拉 | 中 | 洁癖：它是清洁度的活指标 |
| 无毛猫 | 整齐方块 | 盆里，摆得整整齐齐 | 快 | 强迫症玩家最爱 |
| 小猫 | 迷你豆（一次 3 颗） | 到处 | 很快 | 屎多但小 |
| 黑猫 | 螺旋，夜间才拉 | 屋顶 | 慢 | 只有手电/紫外灯照得到 |

- **猫图鉴**：每只猫的第一次来访解锁条目，含拉屎形状与偏好点位。收集猫 = 收集屎的分布图。
- 猫会**带礼物**（Neko Atsume）：偶尔铲到某只猫的屎后掉稀有物件（鱼骨头、毛线球、一片羽毛）。

### 4.1 猫的行为规则（唯一会给玩家「压力」的地方）

1. 盆里屎数 ≥ 盆容量，或盆里有「臭气」阶段的屎 → 猫不用盆，去院子偏好点位拉。
2. 清洁度决定来去：≥ 70% 明天 +1 猫（受后院容量限制）；< 30% 明天 -1 猫（最少 1 只）。
3. 猫永远不会攻击玩家、不会生病、不会死。

## 5. 找屎：感知而非推理

- 院子里的屎初始**不直接可见**：只看到点位（花坛、鞋、草丛、屋顶）在「有东西」时的微动效。
- 屎自己会发信号：新鲜时冒气、招苍蝇时苍蝇绕圈、臭气时绿波纹。玩家看见信号就点，是**感知**不是找茬。
- 工具逐级吃掉这个环节：手电（点位提示）→ 紫外灯（全场屎发光）→ 嗅探狗（自动跑到屎旁站着叫）→ 无人机（小地图标点）。
- 找屎从新鲜感到被自动化淘汰，正好是「手动 → 工具 → 自动」的进化线。

## 6. 工具与升级树（单树、线性为主，不需要构筑）

### 6.1 铲（动词本体）
| 等级 | 名称 | 效果 |
|---|---|---|
| 1 | 塑料铲 | 一铲一坨 |
| 2 | 宽口铲 | 铲半径 +40%，可一铲多坨 |
| 3 | 筛砂铲 | 铲半径 +80%，结块阶段收益 ×1.3 |
| 4 | 电动铲 | 铲半径 +150%，连击窗口延长 |
| 5 | 耙子 | 院子里一铲一排 |
| 6 | 铲屎机甲 | 全场一铲 |

### 6.2 体力 / 手
- 体力上限（手酸阈值）· 握力（连击倍率上限）· 咖啡（体力恢复）· 健身房（每铲 -体力 减少）· 护腕（重铲不掉连击）

### 6.3 猫砂与盆
- 结团猫砂（演变速度 -30%）· 除臭猫砂（跳过臭气阶段）· 第 2/3/4 个盆 · 大号盆（容量）

### 6.4 找屎工具
- 手电 → 紫外灯 → 嗅探狗 → 无人机（见 §5）

### 6.5 自动化（idle 层）
- 自动猫砂盆（每 N 秒自动清一坨，收益 ×0.5）· 改装扫地机（院子巡逻）· 兼职铲屎官（离线也铲）· 屎无人机 · 堆肥站（屎 → 猫草 → 第二货币，后期）

### 6.6 后院扩建
- 小院（5 猫）→ 中院（10 猫，解锁屋顶/花坛）→ 大院（20 猫，解锁屎山点位）→ 街区（50）→ 猫岛（∞）

## 7. 经济

- **货币：罐头 🥫**。铲屎掉罐头（猫的谢礼）。
- 一坨基础值 = 1 罐头 × 阶段倍率 × 猫倍率 × 连击倍率 × 铲子倍率。
- **连击**：0.8s 内连续铲中 → 连击 +1，倍率 1 + 0.1×连击，上限由握力决定（初始 ×2）。
- 商店价格几何增长（×1.6/级）。目标：每天能买 1~2 样，永远有下一个够得到的目标。
- **收藏品**（蘑菇、化石、猫礼物）不换钱，只进图鉴，图鉴里程碑送一次性罐头。

## 8. 转生：搬家

- 主线后期解锁「搬家」：带着**老铲屎官传承点**到更大的后院重开。
- 传承点买永久：初始铲子等级、初始猫数、连击起点、罕见猫概率。
- 重开前 10 分钟飞快是转生爽感的来源。不强制，不搬也能挂机。

## 9. 离线与挂机

- 离线时猫照拉照攒（有上限 = 盆容量 + 院子点位数 + 屎山），**不扣清洁度**。
- 回来满院子是**回来收庄稼**，不是烂摊子。自动化设施离线也工作（收益打折）。

## 10. 美术与音效

- 画风：扁平、圆角、emoji 质感；巧克力色系屎 + 草绿后院 + 米色猫砂。所有屎都有两点眼一条笑。
- 屎的每个演变阶段是**独立精灵**（不是叠 overlay 凑合）。
- **音效三件套**（ASMR 级，比画面更重要）：
  - 沙沙（铲入猫砂，白噪声短促）
  - 咔（结块整块起来，短促清脆）
  - 叮（罐头到账，正弦音高随连击上升）
  - 附：猫呼噜（低频颤音，铲干净时）· 苍蝇嗡（提示）· 轰 + 罐头雨（屎山崩）
- 屏幕反馈：铲中微震 2px、颗粒（砂 + 屎屑 + 罐头）、连击数字放大弹出。

## 11. 界面

- 竖屏 480×720 逻辑分辩率，手机单手。桌面居中。
- 顶部 HUD：第 N 天 · 罐头 · 体力条 · 清洁度条 · 猫数/容量。
- 主画面：后院（草地 + 盆 + 点位 + 猫游走）。
- 底部：收工按钮。
- 日结弹层：今日铲了 N 坨 / 连击最高 / 猫来去 / 商店 / 下一天。
- 图鉴页：猫 · 屎形状 · 收藏品。

## 14. 风险

1. **恶心线**：屎写实一分就完。全部用可爱形态，测试时给不玩游戏的人看截图，有人皱眉就改。
2. **动词单调**：增量游戏 5 小时同一个铲动作会腻。铲子每级必须**看得出**不一样（半径、动画、一排/一片）。
3. **等待感**：早期猫少屎少，玩家干等。对策：初始猫拉屎间隔短（3s），体力 15 下，一天 ≈ 45s；「收工」随时可点。
4. **与 CatStroke 撞题材**：可合并（撸猫 = 猫满意度 · 铲屎 = 院子清洁度），或本作取代之。铲的增量空间更大。

## 15. v0.1 验收标准

- [ ] 手机 Safari/Chrome 打开即玩，无安装、无登录。
- [ ] 点击 → 沙沙/咔/叮三段音效 + 颗粒 + 数字，延迟 < 50ms。
- [ ] 屎 6 阶段肉眼可辨，每阶段外观不同。
- [ ] 连续 3 天内能买到第一件升级，第 5 天前看到屎山并崩过一次。
- [ ] 猫数随清洁度变化，玩家能说出「为什么猫走了」。
- [ ] 关掉页面再开，进度在。
